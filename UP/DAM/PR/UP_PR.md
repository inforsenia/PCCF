## UP01: INTRODUCCION A LA PROGRAMACIÓN Y JAVA
### 1. Identificación
| Campo | Detalle |
| :--- | :--- |
| **Código** | UP01 |
| **Módulo** | Programación (0485) |
| **Duración** | **24 Horas** |
| **Temporalización** | Del **10/09/2026** al **30/09/2026** |

### 2. Fundamentación
**Resultado de Aprendizaje**
*   **RA01.** Reconoce la estructura de un programa informático, identificando y relacionando los elementos propios del lenguaje de programación utilizado.

**Criterios de Evaluación**
*   **a)** Se han identificado los bloques que componen la estructura de un programa informático.
*   **b)** Se han creado proyectos de desarrollo de aplicaciones.
*   **c)** Se han utilizado entornos integrados de desarrollo.
*   **d)** Se han identificado los distintos tipos de variables y la utilidad específica de cada uno.
*   **e)** Se ha modificado el código de un programa para crear y utilizar variables.
*   **f)** Se han creado y utilizado constantes y literales.
*   **g)** Se han clasificado, reconocido y utilizado en expresiones los operadores del lenguaje.
*   **h)** Se ha comprobado el funcionamiento de las conversiones de tipo explícitas e implícitas.
*   **i)** Se han introducido comentarios en el código.

**Competencias**
*   **Profesionales:** e), j), q), w).
*   **Ocupación:** e), j), t), w).

### 3. Organización
**Contenidos**
*   Introducción a la programación: algoritmos, programas y lenguajes de programación.
*   Clasificación de los lenguajes: alto/bajo nivel, interpretados/compilados, paradigmas.
*   Entornos de desarrollo integrados (IDE): elementos y uso del IDE (IntelliJ IDEA / VS Code).
*   El JDK: JVM, JRE, compilador `javac` y empaquetador `jar`.
*   Proyectos Java: estructura de carpetas, paquetes (`package`) e `import`.
*   Variables: declaración, tipos primitivos (`int`, `double`, `boolean`, `char`) y `String`.
*   Literales y constantes (`final`).
*   Operadores: aritméticos, relacionales y lógicos. Expresiones.
*   Conversiones de tipo: automáticas y *casting* explícito.
*   Comentarios: de línea (`//`), de bloque (`/* */`) y JavaDoc (`/** */`).
*   Funciones de librería de las clases `Math` y `String`.
*   Normas y estilo de codificación: nomenclatura, indentación, separaciones y organización de ficheros.
*   Flujos de entrada y salida: concepto de *stream*, `System.in` y `System.out`.
*   Entrada desde teclado con `Scanner`: `nextInt()`, `nextDouble()`, `nextLine()`.
*   Salida por pantalla: `print()`, `println()`, `printf()` y `DecimalFormat`.

**Metodología**
*   Metodologías activas centradas en el alumnado. El aprendizaje se organiza en torno a **prácticas guiadas de programación** donde el estudiante construye, de forma incremental, pequeños programas Java usando el IDE, descubriendo los conceptos a medida que los necesita.

**Secuencia de actividades**
*   **A1:** Introducción a la programación y al IDE. Creación del primer proyecto Java ("Hola Mundo"). Identificación de la estructura básica de un programa.
*   **A2:** Variables y tipos de datos. Declaración, asignación y uso de variables de diferentes tipos en un programa sencillo.
*   **A3:** Constantes, literales y operadores. Escritura de expresiones con operadores aritméticos, relacionales y lógicos.
*   **A4:** Conversiones de tipo (automáticas y *casting*) y comentarios JavaDoc. Documentación del código desarrollado.
*   **A5:** Flujos de E/S. Lectura de datos desde teclado y salida formateada por pantalla.

**Recursos**
*   Equipos del aula de informática, IDE Java (VS Codium), JDK y aula virtual (Aules).

### 4. Evaluación y adaptación

**Instrumentos de evaluación**
La evaluación será continua y formativa, enfocada en la adquisición de los criterios de evaluación del RA01.
*   **Rúbricas de prácticas (20%):** valoración sistemática de los programas desarrollados en cada actividad, atendiendo a la corrección técnica, el estilo de codificación y la documentación.
*   **Pruebas objetivas (80%):** prueba teórico-práctica al finalizar el RA para verificar el cumplimiento de los criterios de evaluación.

**Adaptaciones**
*   **Medidas según necesidades:** las adaptaciones se aplicarán de manera flexible tras la evaluación inicial y el seguimiento diario del progreso del alumnado.
*   **DUA:** se empleará el **Diseño Universal para el Aprendizaje**, proporcionando materiales en múltiples formatos y permitiendo la flexibilización de tiempos en las actividades prácticas.

## UP05: ESTRUCTURAS DE DATOS
### 1. Identificación
| Campo | Detalle |
| :--- | :--- |

### 2. Fundamentación

**Resultados de Aprendizaje**
*   **RA06.** Escribe programas que manipulen información seleccionando y utilizando tipos avanzados de datos.

**Criterios de Evaluación**
*   **a)** Se han escrito programas que utilicen matrices (arrays).
*   **b)** Se han reconocido las librerías de clases relacionadas con tipos de datos avanzados.
*   **c)** Se han utilizado listas para almacenar y procesar información.
*   **d)** Se han utilizado iteradores para recorrer los elementos de las listas.
*   **e)** Se han reconocido las características y ventajas de cada una de las colecciones de datos disponibles.
*   **j)** Se han utilizado operaciones agregadas para el manejo de información almacenada en colecciones.

**Competencias**

**Competencias**
*   **Profesionales:** e), j), q), w).
*   **Ocupación:** e), j), t), w).

### 3. Organización

**Contenidos**
*   Concepto de estructura de datos: organización y almacenamiento de información para facilitar su acceso y manipulación.
*   Arrays: características, declaración, creación e inicialización.
*   Acceso a los elementos de un array mediante índices.
*   Recorrido y modificación de los elementos de un array.
*   Arrays multidimensionales y representación de tablas de datos.
*   Limitaciones de los arrays: tamaño fijo y necesidad de gestionar manualmente determinadas operaciones.
*   Introducción a las estructuras de datos dinámicas y a las colecciones de Java.
*   `ArrayList`: características, declaración, creación y principales operaciones.
*   Inserción, consulta, modificación y eliminación de elementos en un `ArrayList`.
*   Recorrido de un `ArrayList` mediante bucles e iteradores.
*   Comparación entre arrays y `ArrayList`: características, ventajas y limitaciones.
*   Concepto de pila (*stack*): estructura LIFO (*Last In, First Out*).
*   Operaciones básicas de una pila: inserción (`push`), consulta del elemento superior (`peek`) y extracción (`pop`).
*   Implementación de pilas mediante las clases de la API de colecciones de Java.
*   Concepto de cola (*queue*): estructura FIFO (*First In, First Out*).
*   Operaciones básicas de una cola: inserción (`offer`/`add`), consulta del primer elemento (`peek`) y extracción (`poll`/`remove`).
*   Implementación de colas mediante las clases e interfaces de la API de colecciones de Java.
*   Comparación entre arrays, `ArrayList`, pilas y colas según sus características y operaciones disponibles.
*   Selección de la estructura de datos más adecuada según las necesidades de una aplicación.

**Metodología**
*   Metodologías activas basadas en **prácticas de programación** progresivas. El alumnado trabaja con diferentes estructuras de datos para almacenar, consultar, modificar y eliminar información. Se comienza con arrays y se evoluciona hacia estructuras dinámicas y especializadas como `ArrayList`, pilas y colas, comparando sus características y seleccionando la estructura más adecuada para cada problema.

**Secuencia de actividades**
*   **A1:** Introducción a las estructuras de datos. Creación, inicialización, acceso, modificación y recorrido de arrays.
*   **A2:** Arrays multidimensionales y resolución de problemas mediante tablas de datos.
*   **A3:** Introducción a las colecciones de Java. Creación y utilización de `ArrayList`: inserción, consulta, modificación, eliminación y recorrido de elementos.
*   **A4:** Pilas: concepto LIFO y operaciones `push`, `pop` y `peek`. Resolución de problemas mediante estructuras de tipo pila.
*   **A5:** Colas: concepto FIFO y operaciones de inserción, consulta y extracción. Resolución de problemas mediante estructuras de tipo cola.
*   **A6:** Comparación y selección de estructuras de datos. Desarrollo de una aplicación que utilice arrays, `ArrayList`, pilas y colas según las necesidades de cada parte del problema.
