## UP01: INTRODUCCIÓN A LAS BBDD
### 1. Identificación
| Campo | Detalle |
| :--- | :--- |
| **Código** | UP01 |
| **Módulo** | Bases de Datos |
| **Duración** | **8 horas** |
| **Temporalización** | Del **08/09/2025** al **18/09/2025** |

### 2. Fundamentación
**Resultado de Aprendizaje**
* **RA1.** Reconoce los elementos de las bases de datos y de los sistemas gestores, relacionándolos con las necesidades de almacenamiento y tratamiento de la información.

**Criterios de evaluación propuestos**
* Se han diferenciado datos, información y sistemas de información.
* Se han identificado las características de los ficheros, las bases de datos y los SGBD.
* Se han reconocido las funciones básicas de un SGBD y los niveles de la arquitectura ANSI-SPARC.
* Se han relacionado las fases del desarrollo de un sistema de información con el diseño de una base de datos.

**Competencias**
* Se propone trabajar la organización de la información, la autonomía en el uso de herramientas y la comunicación técnica.

### 3. Organización
**Contenidos**
* Sistemas de información: datos, información, hardware, software, procedimientos y recursos humanos.
* Ficheros, registros, campos y operaciones de un sistema gestor de ficheros.
* Bases de datos y sistemas gestores de bases de datos.
* Funciones de un SGBD: almacenamiento, consulta, integridad, seguridad, concurrencia y copias de seguridad.
* Arquitectura ANSI-SPARC: niveles externo, conceptual e interno.
* Fases de desarrollo de un sistema de información.

**Metodología**
* Propuesta de aprendizaje activo mediante análisis de ejemplos próximos, comparación de sistemas de ficheros y bases de datos y pequeñas actividades de identificación conceptual.

**Secuencia de actividades propuesta**
* **A1:** Datos, información y sistemas de información.
* **A2:** Ficheros, registros y campos. Actividad sobre archivos encadenados.
* **A3:** Bases de datos, SGBD y arquitectura ANSI-SPARC.
* **A4:** Comparación de SGBD y síntesis de las fases de desarrollo.

**Recursos**
* Presentaciones de UP1, aula virtual Aules, equipos del aula y un SGBD de referencia.

### 4. Evaluación y adaptación
**Instrumentos de evaluación propuestos**
* Actividades y ejercicios de conceptos: **30%**.
* Investigación comparativa de SGBD y exposición o entrega: **30%**.
* Prueba objetiva de la unidad: **40%**.

**Adaptaciones**
* Materiales escritos y visuales, ejemplos graduados, apoyo guiado en las actividades y flexibilización de tiempos según la evaluación inicial.

* Se han creado y modificado bases de datos, tablas y restricciones.
