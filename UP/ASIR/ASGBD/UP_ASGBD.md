## UP01: Características de un Sistema Gestor de Base de Datos
### 1. Identificación
*   **Código:** UP01 | **Módulo:** 0377
*   **Duración:** 4 horas.
*   **Temporalización:** Primer Trimestre.

### 2. Fundamentación (Real Decreto 1629/2009)
*   **Resultado de Aprendizaje:**
    *   **RA01:** Implanta sistemas gestores de bases de datos analizando sus características y ajustándose a los requerimientos del sistema.
*   **Criterios de Evaluación:**
    *   a) Se ha reconocido la utilidad y función de cada uno de los elementos de un sistema gestor de bases de datos.
    *   b) Se han analizado las características de los principales sistemas gestores de bases de datos.
    *   c) Se ha seleccionado el sistema gestor de bases de datos.
*   **Competencias:**
    *   **Profesionales:** d) Implantar y gestionar bases de datos instalando y administrando el software de gestión en condiciones de calidad.
    *   **Empleabilidad:** 16. Innovación; 18. Resolución de problemas.

### 3. Organización
*   **Contenidos (Orden 36/2012):** Sistemas gestores de bases de datos: evolución, funciones y componentes. Arquitectura ANSI/SPARC. Sistemas gestores de bases de datos comerciales y de software libre. Criterios de selección de un SGBD según las necesidades de explotación.
*   **Teoría:** Material creado por la profesora. Disponible en Aules.
*   **Metodología:** Metodologías activas basadas en el aprendizaje por proyectos: implantación del SGBD para un caso de negocio propuesto.
*   **Secuencia (Fases):**
    *   **E1:** Actividad: Análisis de los componentes y la arquitectura de un SGBD comercial.
    *   **E2:** Actividad: Comparativa razonada entre SGBD comerciales (Oracle, SQL Server) y libres (MySQL, PostgreSQL) para justificar una selección.

### 4. Recursos Tecnológicos
*   **Base Tecnológica:** Equipos con Sistema Operativo Linux/Windows, máquinas virtuales (VirtualBox/VMware), documentación oficial de los SGBD.

### 5. Evaluación y Adaptación
*   **Instrumentos:** Práctica obligatoria (100% de la nota del RA01, según el esquema de evaluación de la programación didáctica).
*   **Adaptaciones:** Aplicación de Diseño Universal para el Aprendizaje (DUA) y ritmos flexibles según necesidades detectadas.
